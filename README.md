# CPM2 METAIMPERIYA Telegram Bot

Бот работает как отдельный Render Background Worker на `aiogram` и получает обновления через long polling. Публичный webhook и `WEBHOOK_URL` для текущего режима не нужны.

## Запуск

1. Создай бота через `@BotFather` и добавь токен в переменные окружения как `BOT_TOKEN`.
2. В Render используй `render.yaml` из этого репозитория. Сервис запускается командой `python bot.py`.
3. Добавь бота администратором в каналы и группы, куда он должен публиковать объявления, и выдай право отправлять сообщения.

Идентификаторы администраторов задаются в `bot.py` в `ADMIN_IDS`; проверка прав выполняется по числовому Telegram ID, не по username.

## Сейчас в боте

- подача объявлений с фото/видео и игровым ID;
- очередь одобрения у администраторов;
- публикация одобренных объявлений в тематические Telegram-каналы;
- меню автомобилей, аккаунтов, услуг, сообщества и гонок.

## Общие CPM2 Sell / Trade сайта и бота

CPM2 объявления об автомобилях из бота используют существующий Firebase сайта. Привяжи Telegram к аккаунту сайта в CPM2: создай код на сайте и отправь боту `/link КОД`. Код одноразовый и действует 10 минут; для отвязки есть `/unlink`. Затем подавай Sell/Trade: заявка появится в комиссионном гараже сайта и пройдёт уже существующую модерацию. После одобрения сайт покажет машину в авторынке и общей ленте, а бот опубликует её в `SALE_CHANNEL` или `TRADE_CHANNEL`.

В Render задай секрет `FIREBASE_SERVICE_ACCOUNT_JSON` как содержимое JSON service account того же Firebase-проекта сайта. `FIREBASE_DATABASE_URL` и `FIREBASE_STORAGE_BUCKET` уже заданы в `render.yaml`; при необходимости оставь им значения из `js/core/firebase.js`. Сервисный ключ нужен только боту и не должен попадать в GitHub. Добавь бота в каналы Sell/Trade с правом публикации.

Остальные старые объявления бота продолжают жить в SQLite (`data/bot_database.db`) и проходят его прежнюю модерацию. В эту общую схему включены только CPM2 автомобильные Sell/Trade объявления.
